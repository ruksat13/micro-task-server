# MicroTask Server

## Live Server URL
https://micro-task-server-36m8.onrender.com

## Tech Stack
- Node.js, Express.js, MongoDB Atlas
- JWT Authentication
- CORS enabled for Netlify client

## API Routes
- POST /jwt - Generate token
- GET/POST /users - User management
- GET/POST /tasks - Task management
- GET/POST /submissions - Submission management
- GET/POST /withdrawals - Withdrawal management
- GET/POST /payments - Payment management
- GET/POST /notifications - Notification system
- GET /admin-stats - Admin statistics
- GET /top-workers - Top 6 workers by coins
